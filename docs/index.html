#217

Contains Duplicate

Easy feito com dicas 1º leetcode ✔

Aqui eu entendi O(n) de verdade! 🎉

O problema: a lista tem algum número repetido? Se sim, true. Se não, false.

[1, 2, 3, 1]  →  true    // o 1 aparece 2x
[1, 2, 3, 4]  →  false   // ninguém repete

A ideia

O computador olha uma carta por vez. Pra saber se uma carta é repetida, ele precisa lembrar das que já viu. Pra isso ele usa um caderninho.

  1. Vira a carta e olha no caderninho: já está lá? Se sim, return true.
  2. Se não está, anota no caderninho.
  3. Virou todas e nunca repetiu? return false.

Meu código

function containsDuplicate(nums) {
  const caderninho = new Set();   // novo a cada chamada

  for (const num of nums) {       // vira as cartas
    if (caderninho.has(num)) {
      return true;                // já vi → achei!
    } else {
      caderninho.add(num);        // não vi → anota
    }
  }

  return false;                   // DEPOIS do for
}

Erros que eu cometi (e agora sei evitar)

  • ✗

    caderninho.has(nums), com s. Isso pergunta pela lista inteira, que nunca está no caderninho.

    ✓ has(num): pergunta pela carta da vez.

  • ✗

    Caderninho criado fora da função. Ele ficou sujo do teste 1 e o teste 2 achou um 1 que não existia.

    ✓ Criar dentro da função, antes do for. Dentro do for também não serve: ele esqueceria tudo a cada carta.

  • ✗

    return false dentro do for. A função parou já na primeira carta.

    ✓ Colocar depois da } que fecha o for. O return faz a função parar na hora.

O(n), explicado

Com 10 números, o código vira 10 cartas. Com 1 milhão de números, viraria 1 milhão de cartas.

Percebe o padrão?

4 números        →  4 cartas
10 números       →  10 cartas
1.000.000        →  1.000.000 cartas

O trabalho cresce junto com o tamanho da lista. Na entrevista isso tem um nome: O(n), que se lê "ó de ene".

  • n = quantos números tem a lista
  • O(n) = "o trabalho é mais ou menos n"

Pronto, é só isso. Quando o entrevistador perguntar qual a complexidade, você responde:

"O(n), porque eu passo por cada número uma vez."

E sem o caderninho? O jeito lento: O(n²)

O(n²) n × n
4 × 4 = 16 4 × 2 = 8 multiplica por ele mesmo, não dobra!

Sem poder anotar, eu decoro um número e comparo com todos os outros. Depois o próximo, e assim vai. Ou seja: todo mundo com todo mundo.

decorei o 1:  comparo com 2, 3, 4   → 3

O que é o ² ?

Ao quadrado = multiplicar o número por ele mesmo. Não é dobrar!

dobrar         →  3 × 2 = 6
ao quadrado    →  3 × 3 = 9
n²             =  n × n

É um quadrado: cada carta comparada com cada carta, n de largura × n de altura.

Na entrevista eu escolho o caderninho. Dica: dá pra começar falando do jeito lento e depois dizer "dá pra melhorar pra O(n) usando um Set". O entrevistador adora ver isso.

Ferramentas de JavaScript

Set é o caderninho

add anota, has pergunta se já está lá.

const c = new Set();
c.add(7);
c.has(7);  // true
c.has(5);  // false (nunca anotei)

for...of vira as cartas

Entrega o valor de cada item, um por vez. Não precisa de índice.

for (const num of [1, 2, 3, 1]) {
  // num: 1, 2, 3, 1
}

Índice x quantidade

O índice começa no 0, então o último índice é o tamanho menos 1.

índice:  0  1  2  3
valor:  [1, 2, 3, 1]   // 4 itens
